WM_S2014_16 · Welding Metallurgy, Spring 2014 · §2.p2

Repeatedly invoked as the canonical example of a mandatory welding code — its "shall"/"should" usage, its pre-qualified procedures, its eight-section structure, and its index. Used by Balfour as the reference frame against which all CWI work is anchored.

An example of a code is the Structural Welding Code that you've probably heard of in this class. It gives the legal rules. It uses the word "shall" when something is mandatory, and "should" when something is just recommended. Anytime there's something in the code that says you "shall" do this, and your contract specifications say you need to follow AWS D1.1, then that's mandatory. There's no debating it.
